# BookNest

BookNest is a book library website made for Lab 1 of the Internet Programming course (HTML, CSS, JavaScript and Git).

## Features
- Catalog of 20 books with real covers from Open Library
- Search by title or author
- Filter by genre
- Book details page (click a book title to open it)
- Availability status (Available / Checked out)
- Modern, responsive design

## Project structure
- `index.html` - catalog page
- `book.html` - book details page
- `css/style.css` - styles
- `js/data.js` - list of books
- `js/main.js` - catalog: rendering, search and filters
- `js/book.js` - details page

## How to run
1. Download or clone the repository.
2. Open `index.html` in a web browser.

An internet connection is needed to load the book covers. If a cover cannot be loaded, a colored cover is shown instead.

## Technologies
HTML5, CSS3, JavaScript, Git and GitHub
